# raw/ — immutable sources

Source material the wiki is compiled from. **Never edit or delete files here** (the LLM only reads them).
Add new material as a new dated file: `YYYY-MM-DD-short-topic.md` (or a sample file under `raw/samples/`).

Good things to drop here: user decisions and requirement changes, research notes (feed probes, API
experiments), Apple docs excerpts, bug reports, device test results, screenshots.
Then ask the agent to "ingest raw/<file>" (see CLAUDE.md).
